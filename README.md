## 🛠️ Features

- **IMEI Validator** — validates any 15-digit IMEI using the international Luhn algorithm
- **Device Lookup** — quick reference for popular phones (iPhone, Samsung, Xiaomi, Tecno, Infinix, Itel)
- **Carrier Unlock Assistant** — generates the exact email template to send to Digicel, Natcom, or any carrier
- **Personal Consultation** — paid 1-on-1 support via WhatsApp (MonCash payment)
- **Trust & Safety panel** — clear explanation of what the app does and does NOT do

## 🚀 Deploy to Streamlit Cloud

### Step 1 — Create the GitHub repo

1. Go to https://github.com/new
2. Name it `unlock-your-phone`
3. Set it to **Public**
4. Click **Create repository**

### Step 2 — Upload the files

Upload these three files to the repo:
- `app.py`
- `requirements.txt`
- `README.md`

### Step 3 — Deploy on Streamlit Cloud

1. Go to https://share.streamlit.io
2. Sign in with your GitHub account
3. Click **New app**
4. Select your repo `unlock-your-phone`
5. Branch: `main`
6. Main file path: `app.py`
7. Click **Deploy!**

Your app will be live at a URL like:
`https://unlock-your-phone.streamlit.app`
